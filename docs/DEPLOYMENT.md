# TradeDeriv Deployment Guide (Neon + Brevo + Deriv + GitHub + Render)

## 1. Fresh Neon PostgreSQL Setup
1. Create a new database in Neon (`https://neon.tech`) and copy its connection string (`DATABASE_URL`).
2. The server automatically runs `database/schema.sql` and seeds initial roles/settings on startup.
3. No admin account is pre-seeded on a fresh database—on first deploy you will create your Owner email and password directly from the hidden setup console.

*(Optional)* If you are reusing an existing Neon database and want to reset it to first-deploy state so the Owner can set a new email and password:
```sql
DELETE FROM application_settings WHERE setting_key = 'admin_credentials';
UPDATE users
SET role_id = (SELECT id FROM roles WHERE name = 'trader' LIMIT 1)
WHERE role_id = (SELECT id FROM roles WHERE name = 'admin' LIMIT 1);
```

## 2. Official Deriv App Registration
1. Visit `https://developers.deriv.com/` and register your application.
2. Copy your numeric App ID into `DERIV_APP_ID` and `VITE_DERIV_APP_ID` (and `DERIV_CLIENT_SECRET` if using Deriv OAuth2).
3. Set the OAuth Redirect URL in Deriv Developer Portal to `https://<your-render-domain>/api/deriv/oauth/callback`.

## 3. Brevo Transactional Email
1. Create an API key in Brevo (`https://app.brevo.com/`) and set `BREVO_API_KEY`.
2. Verify your sender email/domain (`BREVO_SENDER_EMAIL`).

## 4. Render Blueprint Deployment via GitHub
1. Push the repository to GitHub.
2. In Render Dashboard, click **New + -> Blueprint** and select your GitHub repository.
3. Render reads `render.yaml` and provisions a new unified Web Service named `tradederiv` (`npm install --include=dev && npm run build`, `npm start`).
4. Fill in your environment variables (`DATABASE_URL`, `DERIV_APP_ID`, `VITE_DERIV_APP_ID`, `DERIV_CLIENT_SECRET`, `BREVO_API_KEY`, `BREVO_SENDER_EMAIL`, and after provisioning set `FRONTEND_URL` and `DERIV_OAUTH_REDIRECT_URI` to your Render domain).
   - `JWT_SECRET`, `BOT_GATE_JWT_SECRET`, and `TOKEN_ENCRYPTION_KEY` are auto-generated by Render.
5. Verify `GET https://<your-render-domain>/api/health` returns `200 OK`.
6. Open your live site, click/tap the top-bar logo icon **20 consecutive times** (without tapping elsewhere or pausing >2.5s), and complete the **Initialize Owner Account** form on `/_console` to set your Owner email and password.

## 5. Vercel Frontend + Express API Deployment
1. `vercel.json` is configured at the repository root (`buildCommand: npm run build`, `outputDirectory: dist`) with immutable asset caching for `/chart/*` and `/assets/*`.
2. Deploy the Express + WebSocket backend (`apps/api` via `npm start`) on Render/Railway/Fly with PostgreSQL (`DATABASE_URL`), `DERIV_APP_ID`, `DERIV_CLIENT_SECRET`, `JWT_SECRET`, `TOKEN_ENCRYPTION_KEY`, and `GEMINI_API_KEY` (optional for AI summary prose).
3. In Vercel Environment Variables, set `VITE_API_URL=https://<your-api-domain>/api`, `VITE_WS_URL=wss://<your-api-domain>/ws`, and `VITE_DERIV_APP_ID=<your-deriv-app-id>`.
