# Pipflowtrade.site Deployment Guide (Neon + Brevo + Deriv + GitHub + Render)

## 1. Fresh Neon PostgreSQL Setup
1. Create a new database in Neon (`https://neon.tech`) and copy its connection string (`DATABASE_URL`).
2. On startup the server automatically runs `apps/api/src/database/init.ts` (matching `database/schema.sql`, `database/migrations/001–003`, and `database/seeds/seed.sql`).
3. No Owner account is pre-seeded on a fresh database—on first deploy you initialize your Owner email and password directly via the console entry (`/ops/<ADMIN_PRIVATE_SLUG>` or `/_console`).

*(Optional)* To reset an existing database to first-deploy state:
```bash
CONFIRM_DB_REBUILD=YES npm run db:rebuild -- --confirm
```

## 2. Official Deriv App Registration
1. Visit `https://developers.deriv.com/` and register your application.
2. Copy your OAuth Client ID / App ID into `DERIV_APP_ID` and `VITE_DERIV_APP_ID` (and `DERIV_CLIENT_SECRET` for OAuth2 PKCE token exchange).
3. Configure the OAuth Redirect URL in Deriv Developer Portal to:
   `https://pipflowtrade.site/api/deriv/oauth/callback`

## 3. Brevo Transactional Email
1. Create an API key in Brevo (`https://app.brevo.com/`) and set `BREVO_API_KEY`.
2. Verify your sender email/domain (`BREVO_SENDER_EMAIL=noreply@pipflowtrade.site`).

## 4. Render Blueprint Deployment via GitHub
1. Push the repository to GitHub.
2. In Render Dashboard, click **New + -> Blueprint** and select your GitHub repository.
3. Render reads `render.yaml` and provisions the unified Node.js Web Service (`pipflowtrades`) with:
   - `buildCommand: npm install --include=dev && npm run build`
   - `startCommand: npm start`
   - `healthCheckPath: /api/health`
   - Custom domains: `pipflowtrade.site` and `www.pipflowtrade.site`
4. Populate required Render secrets/env vars:
   - `DATABASE_URL` (Neon PostgreSQL connection string with SSL)
   - `DERIV_APP_ID`, `VITE_DERIV_APP_ID`, `DERIV_CLIENT_SECRET`
   - `BREVO_API_KEY`, `BREVO_SENDER_EMAIL`
   - Optional: `GEMINI_API_KEY`, `XAUUSD_FEED_PROVIDER`, `XAUUSD_FEED_URL`
   - Auto-generated by Render Blueprint: `JWT_SECRET`, `BOT_GATE_JWT_SECRET`, `TOKEN_ENCRYPTION_KEY`, `ADMIN_PRIVATE_SLUG`
5. Verify `GET https://pipflowtrade.site/api/health` returns `200 OK` with `database.ok: true`.
6. Open `https://pipflowtrade.site`, click/tap the top-bar logo icon **20 consecutive times** (or visit `/#/ops/<ADMIN_PRIVATE_SLUG>`), and submit the **Initialize Owner Account** form to create the sole platform **OWNER** account.
